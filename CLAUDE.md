# CLAUDE.md

This repo is the rule source other LLM sessions run on. Work here is writing
rules, and the reader is an LLM.

- Follow the repo's own rules while editing it; start at main.md.
- Write every rule to be as error-proof as possible for the reading model:
  unambiguous structure, exact strings where exactness matters, one anchoring
  example over abstract description.
- When a claim about LLM behavior decides a rule, prefer research over
  intuition, and log what was found in sources.md: one line, link, what it
  shaped.
- Changes follow workflow.md section 4: propose, wait for jarl's yes, then
  write.
